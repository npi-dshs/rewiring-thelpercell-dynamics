2.2 Outlier and Influence Diagnostics

Custom functions - required for all outlier analyses below.

The following four functions implement the leave-one-out standardised residual approach described in Hedges and Olkin (1985) and Viechtbauer and Cheung (2010). A study is classified as an outlier if its standardised residual exceeds |3|; values above |1.96| warrant closer inspection. The model (fixed- vs. random-effects) is selected automatically from the robust heterogeneity index Ir² (< 30% → fixed-effects, otherwise random-effects). The outlier routine is always passed the variance (seTE^2) as its s2 argument.

## Outlier and Influence Diagnostics

::: infobox
**Custom functions - required for all outlier analyses below.**

The following four functions implement the leave-one-out standardised residual approach described in @hedgesDiagnosticProceduresResearch1985 and @viechtbauerOutlierInfluenceDiagnostics2010. A study is classified as an outlier if its standardised residual exceeds \|3\|; values above \|1.96\| warrant closer inspection. The model (fixed- vs. random-effects) is selected automatically from the robust heterogeneity index *I*r² (\< 30% → fixed-effects, otherwise random-effects). The outlier routine is always passed the **variance** (`seTE^2`) as its `s2` argument.
:::

### Decision procedure

```{mermaid}
%%| echo: false
%%| fig-width: 6.5
flowchart TD
  A["M1 - Primary<br/>random-effects model"] --> B["Leave-one-out standardised residuals<br/><code>metaoutliers(y, s2 = seTE^2)</code>"]
  B --> C{"|z| ≥ 3"}
  C -- no --> D["|z| > 1.96: inspect<br/>otherwise: no outlier"]
  C -- yes --> E["Outlier"]
  A --> F["DFBETAS<br/><code>rma.mv()</code>"]
  F --> G{"|DFBETAS| > 1"}
  G -- yes --> H["Influential case"]
  G -- no --> I["Not influential"]
  E --> J{"Outlier and<br/>influential?"}
  H --> J
  J -- yes --> K["Withdraw and re-fit<br/>M2 - Outlier-adjusted"]
  J -- no --> L["Retain all outcomes<br/>heterogeneity: moderator analyses"]
  D --> L
  I --> L
  classDef model fill:#F0F6FF,stroke:#0078D4,color:#1E1E1E
  classDef flag fill:#FDECEC,stroke:#C62828,color:#8B1A1A
  classDef keep fill:#F7F7F7,stroke:#9AA0A6,color:#1E1E1E
  class A,K model
  class E,H flag
  class D,I,L keep
```
